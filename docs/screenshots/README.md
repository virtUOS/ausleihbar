## Conventions

- Desktop shots: window ~**1300 px** wide, capture the content area (no OS
  chrome); light theme reads best on GitLab (dark-mode shot excepted).
- Keep each file roughly **< 500 KB** (resize to ~1280 px wide).
- Use the seeded **demo catalogue** — never real borrower names or e-mail
  addresses.
- File names are lowercase-with-hyphens. To add more, drop the file here and
  reference it from the README.
