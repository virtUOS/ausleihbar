# Sets

Ein **Set** ist eine Liste von Produkten, die sinnvollerweise zusammen
verliehen werden, zum Beispiel ein Interview-Set aus Kamera, Funkmikrofon
und Stativ. Ausleihende legen das ganze Set mit einem Klick in den Warenkorb
([Sets in der Anleitung](../anleitung/sets.md)).

Sets pflegst du unter Verleihtheke → Bestand → **Sets**. Wie Produkte
gehören sie zum gemeinsamen Katalog; ein Set wird aber immer aus **einem**
Pool gebucht.

## Ein Set anlegen

1. Klicke **+ Neues Set**.
2. **Pool:** Wähle den Pool, aus dem das Set verliehen wird. Du kannst nur
   Pools wählen, die du betreust. Alle Produkte des Sets müssen dort
   Gegenstände haben.
3. **Name:** auf Deutsch und Englisch.
4. **Produkte in diesem Set:** Suche Produkte in der Liste darunter
   („Produkte durchsuchen…“, gruppiert nach Sparte › Kategorie) und füge
   sie hinzu. Mit **−** / **+** stellst du ein, wie viele Gegenstände je
   Produkt dazugehören; „1 benötigt · 3 im Pool“ zeigt, wie viele es im
   Pool gibt. Mit den Pfeilen oder durch Ziehen änderst du die Reihenfolge.
5. **Bilder:** wie beim Produkt; das erste ist das Titelbild.
6. **Beschreibung:** formatierter Text, z. B. wofür sich das Set eignet.
7. **Kategorien:** wo das Set in der Shop-Navigation erscheint.
8. **Speichern.**

!!! warning "Das Formular passt auf"
    Ein Set lässt sich nicht speichern, solange ein Produkt keine
    Gegenstände im gewählten Pool hat („Nicht in diesem Pool“) oder mehr
    Gegenstände verlangt werden, als der Pool hat. Entferne das Produkt
    bzw. verringere die Anzahl.

## So wird ein Set gebucht

- Verfügbar ist ein Set in einem Zeitraum nur, wenn **alle** Produkte in
  der verlangten Anzahl frei sind. Ausleihbar zählt dafür ganze Sets.
- Legt jemand ein Set in den Warenkorb, reserviert Ausleihbar für jedes
  Produkt die verlangte Zahl verschiedener Gegenstände – alles oder nichts.
- Danach ist es eine ganz normale Buchung: Du bestätigst, gibst aus und
  nimmst zurück wie bei einzelnen Gegenständen.
- Wer ein Set sehen darf, richtet sich nach dem Pool: Ist der Pool auf
  bestimmte Zugriffsgruppen beschränkt, gilt das auch für seine Sets.

!!! tip "Sets in den Sparten"
    Die Administration kann Sets zusätzlich direkt einer Sparte zuordnen;
    sie erscheinen dort nach den Kategorien ([Sparten](katalog.md#sparten)).
