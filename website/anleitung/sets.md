# Sets

Ein **Set** bündelt Produkte, die oft zusammen gebraucht werden, zum
Beispiel ein „Interview-Set“ aus Kamera, Funkmikrofon und Stativ. Statt drei
Produkte einzeln zu buchen, wählst du einmal einen Zeitraum, und alles landet
gemeinsam im Warenkorb.

## Sets finden

Sets stehen dort, wo auch Produkte stehen:

- in den Kategorien unter **Produkte und Sets**,
- auf den Kacheln der Sparten (z. B. „8 Produkte · 1 Set“),
- auf jeder Produktseite unter **Teil von Sets**, wenn das Produkt in einem
  Set enthalten ist.

Ein Set erkennst du am Rucksack-Symbol 🎒.

## Ein Set buchen

![Set-Seite „Interview-Set“: Beschreibung „Alles für ein Interview mit zwei Personen“, der Hinweis „Verfügbar in Medienlabor · Raum 1.12“ und die Liste „Produkte in diesem Set“ mit je 1 × Canon EOS R6 Mark II, RØDE Wireless GO II und Manfrotto 190 Stativ](../bilder/set.png)

1. Öffne die Set-Seite. Unter **Produkte in diesem Set** steht, was in
   welcher Anzahl dazugehört; ein Klick auf ein Produkt öffnet seine Seite.
2. **Verfügbar in** nennt den Pool, aus dem das Set kommt. Ein Set gehört
   immer zu genau einem Pool.
3. Wähle im Kalender deinen Zeitraum, genau wie auf einer
   [Produktseite](produkt.md). Die Zahl je Tag sagt, **wie viele ganze
   Sets** an diesem Tag frei sind.
4. Klicke auf **In den Warenkorb**.

Im Warenkorb stehen danach die einzelnen Produkte des Sets. Du kannst sie
dort wie andere Gegenstände behandeln.

!!! note "Alles oder nichts"
    Ein Set kommt nur dann in den Warenkorb, wenn **alle** enthaltenen
    Produkte im Zeitraum frei sind. Fehlt eines, wird nichts hinzugefügt und
    die Meldung nennt das Produkt, das fehlt. Dann hilft ein anderer
    Zeitraum, oder du buchst die übrigen Produkte einzeln.

!!! tip "Ausleihdauer im Set"
    Für ein Set gilt die Ausleihdauer des am stärksten eingeschränkten
    Produkts. Die Set-Seite weist darauf hin, wenn es eine Grenze gibt.

Steht auf der Set-Seite „Dieses Set kann derzeit nicht gebucht werden“, ist
das Set keinem Pool zugeordnet, auf den du Zugriff hast. Frag in dem Fall
das Verleihteam.
