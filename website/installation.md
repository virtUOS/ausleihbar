# Installation

Ausleihbar ist freie Software (Apache-2.0) und läuft als
**Docker-Compose-Stack**: PostgreSQL, Django-Backend und die React-Oberfläche.
Die Anmeldung läuft über den Identity Provider Ihrer Einrichtung (OIDC, z. B.
Keycloak).
