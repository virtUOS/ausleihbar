# Sets

A **set** is a list of products that are sensibly lent together, for
example an interview kit made up of a camera, a wireless microphone and a
tripod. Borrowers add the whole set to their cart with one click
([Sets in the guide](../guide/sets.md)).

You maintain sets under Lending desk → Inventory → **Sets**. Like products,
they belong to the shared catalog; a set, however, is always booked from
**one** pool.

## Creating a set

1. Click **+ New set**.
2. **Pool:** Choose the pool the set is lent from. You can only choose
   pools you look after. All products of the set must have items there.
3. **Name:** in German and English.
4. **Products in this set:** Search for products in the list below
   ("Search products…", grouped by section › category) and add them. Use
   **−** / **+** to set how many items of each product belong to it;
   "1 needed · 3 in pool" shows how many there are in the pool. Use the
   arrows or drag to change the order.
5. **Images:** as for products; the first one is the cover.
6. **Description:** formatted text, e.g. what the set is good for.
7. **Categories:** where the set appears in the shop navigation.
8. **Save.**

!!! warning "The form keeps watch"
    A set can't be saved as long as a product has no items in the chosen
    pool ("Not in this pool") or more items are required than the pool
    has. Remove the product or reduce the quantity.

## How a set is booked

- A set is only available in a period if **all** products are free in the
  required quantity. Ausleihbar counts whole sets for this.
- When someone adds a set to their cart, Ausleihbar reserves the required
  number of different items for each product — all or nothing.
- After that it is a perfectly normal booking: you confirm, hand out and
  take back as with individual items.
- Who may see a set depends on the pool: if the pool is restricted to
  certain access groups, this applies to its sets as well.

!!! tip "Sets in the sections"
    The administration can also assign sets directly to a section; they
    then appear there after the categories ([Sections](catalog.md#sections)).
